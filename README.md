### 📌 Featured Projects

**[HR Attrition Analysis](https://github.com/julfikar1995/HR-Attrition-Analysis)**

MySQL + Power BI analysis of 1,470 employees.
- 🧹 Cleaned the data with 6 quality checks and built SQL views using CTEs and window functions
- 📊 Built a 3-page interactive dashboard with a rule-based risk score and a top-10 watch list
- 💡 Found 16.1% attrition, with overtime (30.5% vs 10.4%) as the strongest signal, and flagged 140 high-risk current employees

**[Excel Sales Dashboard](https://github.com/julfikar1995/excel-sales-dashboard)**

Interactive Superstore sales dashboard built in Excel with Power Query, Data Model measures, PivotTables, slicers and a timeline.

**[E-Commerce Sales & Customer Analytics](https://github.com/julfikar1995/-ecommerce-sales-customer-analytics)**

End-to-end MySQL + Power BI project on 3+ years of e-commerce data.
- 🗄️ Designed a relational database and wrote 15+ SQL queries (joins, subqueries, conditional aggregation)
- 📊 Built a 3-page interactive Power BI dashboard with 10+ DAX measures and synced slicers
- 💡 Uncovered a 64% funnel drop-off, a single-product revenue dependency, and a critical customer retention gap
